# Javaの小さな教室

Javaを初めて学ぶ人向けの日本語ハンズオンアプリです。20レッスンを順番に進め、コードの実行結果でクリアを判定します。詳しい解説、間違えたときのヒント、クリア時のキャラクター演出があります。

## 起動方法

JDK 17以降とPython 3が必要です。ターミナルで次を実行してください。

```sh
cd /Users/shinya_nakashima/codex-practice/java-learning-app
python3 server.py
```

ブラウザで <http://localhost:8001> を開きます。終了はターミナルで `Ctrl+C` です。

Javaコードは一時フォルダに保存して、PCにインストールされた `javac` と `java` でコンパイル・実行します。実行後、一時フォルダは削除されます。コードはこのPC内で動くため、内容を確認できるコードだけを実行してください。
